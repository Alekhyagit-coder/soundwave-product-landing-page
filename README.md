# SoundWave – Product Landing Page

A responsive product landing page for SoundWave Wireless Headphones, built using HTML, CSS, and JavaScript.

## About the Project

SoundWave is a front-end web development project designed to present a wireless headphone product in a clean and user-friendly layout. It displays product details, features, customer review examples, and an interactive Buy Now demo.

## Features

- Responsive product landing page design
- Product image, name, and price display
- Product feature cards
- Customer review section with sample reviews
- Smooth scrolling navigation
- Interactive Buy Now demo message
- Mobile-friendly layout

## Technologies Used

- **HTML5** – Page structure
- **CSS3** – Styling, layout, and responsive design
- **JavaScript** – Button interaction and smooth scrolling

## Project Structure

```text
soundwave-product-landing-page/

```

## How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using the Live Server extension, or open the file directly in your browser.
